# Aprendizaje: Netlify conectado a GitHub

## Qué pasó
La página de Netlify se publica desde un enlace a GitHub, y la descarga del zip se gestiona desde el repositorio.

## Qué aprendimos
Con ese enlace, el zip local no necesita subirse. Solo `index.html` debe volver a arrastrarse a Netlify cuando cambie.
