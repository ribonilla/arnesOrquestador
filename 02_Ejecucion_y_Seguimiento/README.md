# ⚡ 02. Ejecución y Seguimiento

Esta macro-carpeta responde a la pregunta de trabajo: **¿En qué estamos trabajando hoy y cómo avanza el plan?**

Es el taller activo de trabajo colaborativo entre el usuario y el arnés de IA.

---

## 📂 Subcarpetas y Contenidos

### 📋 1. `Kanban_y_Tareas/`
* **Propósito:** El motor visual de avance de tareas por fases.
* **Documentos Clave:**
  - `Tablero_Kanban.base`: Vista interactiva nativa de Obsidian Bases (soporta vistas de tarjetas tipo *Cards* y tablas de control agrupadas por estado).
  - `Tablero_Kanban.md`: Versión legible en Markdown estándar para consultas directas y lectura rápida de fases.
  - `Tareas/TAR_XX_Nombre.md`: Cada hito o entregable se descompone en una nota individual con metadata YAML (prioridad, estado, fase, asignado y fecha límite).

### 💡 2. `Sesiones_y_Borradores/`
* **Propósito:** El espacio de diálogo, debate socrático y trabajo en sucio con la IA.
* **Documentos Clave:**
  - `Sesion_YYYY-MM-DD_HHmm_Tema.md`: Minutas automáticas generadas al finalizar reflexiones, sesiones de ideación o análisis de problemas complejos.
  - El arnés persiste aquí el progreso para que ninguna conversación valiosa se quede perdida en la ventana de chat.
